Third-party software bundled with Netodia
=========================================

Netodia links the work below into its executable -- the fonts
are compiled in rather than loaded from disk, the winit fork is built from this
tree rather than fetched from crates.io, and some crates fetched from crates.io
ask something of whoever ships a binary containing them -- so every artifact we
ship (tarball, AppImage, RPM, DEB and MSI) is a distribution of it. The full
license text for each sits beside this file, except where an entry says there is
none to ship.

Melodia's own license (AGPL-3.0-or-later) ships with this package as LICENSE
and covers none of the software below.

The "Files" lists give each component's path in the source repository, which is
what identifies it -- the fonts, the mark and the fork are inside the binary,
not installed. A crate has no such path; the entry names its version instead,
and Cargo.lock is what pins it.

Debian packages carry a fuller machine-readable version of this at
/usr/share/doc/melodia/copyright; the two are kept in step by
the_debian_copyright_quotes_the_licences_it_ships, in
crates/netodia/tests/packaging.rs.


Vazirmatn
---------
Version 33.003, by Saber Rastikerdar and the Vazirmatn Project Authors.
https://github.com/rastikerdar/vazirmatn

Licensed under the SIL Open Font License, Version 1.1 -- full text in
Vazirmatn-OFL-1.1.txt.

MODIFIED. `scripts/patch_vazirmatn.py` merges in the Greek, Russian, Ukrainian
and Vietnamese letters it lacks from Roboto (see the Roboto entry below), then
rewrites the OS/2 typo and hhea ascent/descent values so glyph mass lands at the
line-box centre under the FemtoVG renderer; upstream's metrics are sized to
clear Arabic combining marks and push centred Latin text upward at the app's UI
sizes. Vazirmatn's own glyph outlines, capHeight, x-height and the usWin* clip
bounds are untouched.

Files:
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-Regular.ttf
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-Medium.ttf
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-SemiBold.ttf

Upstream declares NO Reserved Font Name -- its copyright line names the project
and stops there -- so OFL section 5 imposes no rename on the patched build, and
it keeps the Vazirmatn name. Check this again before bumping to a release whose
copyright line has changed.

Upstream notes that Vazirmatn's non-Arabic glyphs derive from Roboto under the
Apache License 2.0; that combination is upstream's, and their OFL covers the
result.


Roboto
------
Version 3.004, by Google Inc.
https://github.com/googlefonts/roboto-3-classic

Licensed under the Apache License, Version 2.0 -- full text in Apache-2.0.txt.
Upstream ships no NOTICE file, so section 4(d) carries nothing here.

MODIFIED. `scripts/patch_vazirmatn.py` instances the variable font at the three
weights the Vazirmatn faces above ship, subsets each instance to the Greek,
Russian, Ukrainian and Vietnamese letters Vazirmatn lacks (CLDR's exemplar
characters for each language) and the combining marks their decomposed
spellings use, and merges those glyphs, with their kerning and mark
positioning, into the Vazirmatn faces. No outline is altered. This is the
release Vazirmatn's own Latin was imported from, so the added letters match it.

Files:
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-Regular.ttf
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-Medium.ttf
  crates/netodia-ui/ui/assets/fonts/vazirmatn/Vazirmatn-SemiBold.ttf

Merged rather than shipped beside Vazirmatn, so the faces keep the Vazirmatn
name and carry it under upstream's OFL, which is how upstream already ships its
own Roboto-derived Latin.

Material Symbols Rounded
------------------------
Version 2.935, by Google LLC. Outlined (FILL=0) and filled (FILL=1) faces.
https://github.com/google/material-design-icons

Licensed under the Apache License, Version 2.0 -- full text in Apache-2.0.txt.
Upstream ships no NOTICE file, so section 4(d) carries nothing here.

MODIFIED. `scripts/subset-icon-fonts.sh` subsets both faces down to the icon
ligatures listed in `scripts/icons.txt`, by glyph id with --no-layout-closure so
the closure can't pull the rest of the catalogue back in. No outline is altered.

Files:
  crates/netodia-ui/ui/assets/fonts/MaterialSymbolsRounded.ttf
  crates/netodia-ui/ui/assets/fonts/MaterialSymbolsRoundedFilled.ttf

Neither face carries a license string in its name table, in the subsets or in
the pristine upstream sources -- Apache-2.0.txt is the only copy that travels
with them.


winit
-----
Version 0.30.13, by Pierre Krieger and the winit contributors.
https://github.com/rust-windowing/winit

Licensed under the Apache License, Version 2.0 -- full text in Apache-2.0.txt,
the same copy Material Symbols above is under. Upstream ships no NOTICE file.

MODIFIED. The fork carries three commits on top of the v0.30.13 tag: PR #4009
("wayland: register drag & drop events", by PeakKS), a WindowId fixup and URI
percent-decoding. Together they give Wayland the DroppedFile / HoveredFile
events winit has only ever delivered on X11, macOS and Windows
(rust-windowing/winit#1881). The additions are cfg-gated to Linux. Applied
through Cargo's [patch.crates-io], so this is what every platform builds
against; see winit/README.md.

Files:
  winit/*

Vendored in-tree rather than fetched, so a fresh clone and every CI runner build
identically. The whole directory retires once upstream lands native Wayland
drag-and-drop.


The entries below are crates rather than files in this tree. They are named here,
where the hundreds of other crates.io dependencies are not, because each asks
something of whoever ships a binary containing it: four carry a copyleft license,
whose text recipients of the binary are owed, and the fifth ships a NOTICE its
own license asks be reproduced. An artifact we ship is not a published crate, so
neither obligation is met by the crate's own files travelling on crates.io. Each
is unmodified, and the corresponding source for each is the crate as published at
the version Cargo.lock pins.

Symphonia
---------
Version 0.6.1, by Philip Deljanov.
https://github.com/pdeljanov/Symphonia

Licensed under the Mozilla Public License, Version 2.0 -- full text in
MPL-2.0.txt.

Sixteen crates from one project: the core, the container readers and the
decoders. They decode every audio file Melodia plays. MPL-2.0 section 3.2 asks
that recipients of the executable be told the covered source is available under
that license and be given a copy of it, which is what this entry and MPL-2.0.txt

Rust dependencies
-----------------
Everything else Melodia links is an unmodified crate resolved from crates.io and
pinned in Cargo.lock, under permissive terms and predominantly MIT and
Apache-2.0. Those are not listed here individually: they are redistributed
unmodified and their own license files travel in the published crates, where
`cargo license` or a vendored checkout reproduces the set for any given release.
Only the software this repository *modifies*, *carries a copy of*, links under a
*copyleft* license, or ships a *NOTICE* its license asks us to reproduce is
listed individually.
